! ==========================================
! REGEX — variant catching (AdGuard Home / AdGuard DNS only)
! Added 2026-09-02. Source: ozankiratli gist (updated 2026-09-02) + r/pihole 1v7jmeq.
! Exact hostnames above miss prefixed/suffixed and deeper-nested variants:
! amoeba2.roku.com, giga.sb.roku.com, foo.austin.roku.com etc.
! If Roku breaks, delete the codename regex FIRST: it matches substrings in any
! label ("giga", "copper", "external", ...), so it is the broadest rule here.
! ==========================================

! Ad/telemetry labels at any depth.
! 'cti' is not needed here: ||cti.roku.com^ above already covers every subdomain
! (and the ls.cti/tis.cti allows win over any block anyway).
/^(([^.]+\.)*(logs|ads|web|prod\.mobile|voice)(\.[^.]+)*\.)roku\.com$/

! Rotating codename hosts, with characters before/after and deeper subdomains
/^(([^.]+\.)*[^.]*(amarillo|amoeba|austin|benjamin|bryan|camden|cooper|copper|digdug|external|giga|gilbert|griffin|hereford|liberty|littlefield|longview|madison|marlin|midland|paolo|richmond|rollingwood|scribe|sugarland|tyler|victoria|windsor)[^.]*(\.[^.]+)*\.)roku\.com$/

! Roku ad measurement. Roku's own host is roku.adsmeasurement.com (HaGeZi
! native.roku). admeasurement.com is an ad-measurement domain, also in HaGeZi Pro.
||admeasurement.com^
